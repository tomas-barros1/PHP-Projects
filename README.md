# PHP Projects

Collection of 12 beginner PHP exercises from the ["PHP Moderno"](https://www.youtube.com/watch?v=Tfs0OBGvGn0&list=PLHz_AreHm4dlFPrCXCmd5g92860x_Pbr_) course by Curso em Vídeo (Gustavo Guanabara).

## Exercises

| # | Project | Description |
|---|---------|-------------|
| 1 | **Analisar Número Real** | Extracts integer and decimal parts of a real number |
| 2 | **Anatomia de uma Divisão** | Shows quotient and remainder of a division |
| 3 | **Calculadora de Tempo** | Converts seconds into minutes/hours/days/weeks |
| 4 | **Calcular Idade** | Calculates age given birth year and target year |
| 5 | **Consumindo API** | Fetches live USD exchange rate from Brazil's Central Bank |
| 6 | **Conversor de Moedas** | Converts BRL to USD at a fixed rate |
| 7 | **Formulário Retroalimentado** | Self-submitting form showing name + age |
| 8 | **Média Aritimética** | Calculates simple and weighted arithmetic means |
| 9 | **Números Aleatórios** | Generates a random number (0–100) |
| 10 | **Raízes de um Número** | Calculates square root and cube root |
| 11 | **Reajuste de Preços** | Applies a percentage price increase |
| 12 | **Salários Mínimos** | Calculates how many minimum wages a salary represents |

## Tech Stack

- **PHP** (embedded in HTML)
- **HTML5 / CSS3**
- No frameworks or external dependencies

## Setup

```bash
php -S localhost:8000
```

Navigate to each exercise's `index.php` file in your browser.
